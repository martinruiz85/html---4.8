  Created: {1:dd-MMM-yyyy}

  Purpose:
    This SP retrieves a list of Unit records for a specific unit type.
    and in the supplied language. It is used by the FormUnitControl.

  Parameters:
    @vintCurUserID:     Current user context if available. NULL if unknown.
    @vintCurSysLID:     Language for translated text. NULL if unknown.
    @vblnShowAll:       (Optional) 1 to show all available (non-hidden)

                        those applicable to the user based on txUserUnit.

    1:  List of Unit records for a FormUnitControl

  Returns:

/*______________________ CONSTANT DECLARATIONS _________________________*/

    @cstrThisProc              NVARCHAR(128),
    @cintErrGeneral            INT

    @strErrMsg      NVARCHAR(400),
